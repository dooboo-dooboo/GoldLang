프로그래밍 사이트로 이동

골랭 문법

SHOW "Hello World!"; Hello를 출력합니다. SHOW "GET<a>"; a변수의 값을 출력합니다. SET a IS b; a변수의 값을 b로 설정합니다. LIST a IS [1,2,3,4,5]; a리스트의 값을 인덱스별로 각각 1, 2, 3, 4, 5로 설정합니다. GET<a> a의 값을 가져옵니다. INDEX<a,1> a리스트의 1번째 값을 가져옵니다. 단, 인덱스는 0부터 시작입니다. LENGTH<a> a리스트의 길이를 가져옵니다. CHANGE<a,1,3> a리스트의 인덱스 1번 값을 3으로 바꿉니다. NEWLIST<a,6> a리스트의 마지막에 6이라는 값을 추가합니다. DELETE<a,4> a리스트의 인덱스 4번 값을 삭제합니다. ADD<a,b> a와 b의 합을 가져옵니다. SUB(뺄셈), MUL(곱셈), DIV(나눗셈)도 같은 방법입니다. JOIN<a,b> a와 b의 값을 이어줍니다. IF TRUE THEN{ SHOW "Hello"; } True라면 Hello를 출력합니다. True 자리에는 다른 값(TRUE, FALSE)가 들어올 수 있습니다. BIGGER<a,b>는 a,b중 더큰 값, SMALLER<a,b>는 a,b중 더 작은 값을 가져옵니다. SAME<a,b>는 a,b가 같다면 TRUE를, 아니면 FALSE를 반환합니다. NOT<TRUE>는 FALSE, NOT<FALSE>는 TRUE를 반환합니다. REPEAT 5 START{ SHOW "Hello World!"; } 는 Hello World! 출력을 5번 반복합니다. WHILE TRUE THEN{ SHOW "HELLO WORLD!"; } 는 TRUE인 동안 HELLO WORLD!를 출력합니다. WHILE문을 사용 시 주의할 점이 있습니다. SET a IS 1; WHILE SAME<5,BIGGER<GET<a>,5>> START{ SHOW "GET<a>"; SET a IS ADD<GET<a>,1>; } 와 같이 무한루프에 빠지지 않게 하는 것이 중요합니다. FUNCTION func() START{ SHOW "Hello"; } 는 Hello를 출력하는 함수 func를 정의합니다. ()안에 매개변수를 넣을 수 있으며, 이 변수는 함수 밖에서 선언된 변수보다 우선적으로 사용됩니다. 함수 내에서 변수를 만들 시 함수 내에서만 사용 가능하며, 매개변수보다 우선순위가 낮습니다. DO func()는 func 함수를 사용하며, () 안에 매개변수를 입력할 수 있습니다. DELAY 3 DO func()는 3초 후 func 함수를 사용하는 코드입니다. () 안에 매개변수를 입력할 수 있습니다. ALL<a,b>는 a, b 모두 TRUE면 "TRUE"를, 아니면 "FALSE"를 반환합니다. OR<a,b>는 a, b 중 하나라도 TRUE면 "TRUE"를, 아니면 "FALSE"를 반환합니다. ALL, OR 명령어는 쉼표로 구분하여 3개 이상의 값을 넣을 수도 있습니다. STOP; 명령어는 현재 진행중인 반복문이나 함수를 종료하는 명령어입니다. CLASS Pet START{ DEFAULT(name,age) START{ SHOW "SETTING"; } FUNCTION Eat() START{ SHOW "EATING"; } } CLASS는 이런 식으로 선언되며, 반드시 DEFAULT 함수가 있어야 합니다. DEFAULT함수 앞에는 FUNCTION을 붙이지 않습니다. DEFAULT함수 내부에는 아무 코드도 없어도 됩니다. NEW pet IS PET(cat1,5); 이 코드는 PET클래스로 name이 cat1, age가 5인 변수를 선언합니다. FROM pet DO Eat(); 이 코드는 클래스로 만든 변수 pet의 Eat() 함수를 실행합니다. GET_CLASS_VAR<pet,age> 이 코드는 클래스로 만든 변수 pet의 age변수 값을 가져옵니다. CLASS_LIST 코드는 LIST 코드와 동일하며, 리스트 내부에 클래스 변수 이름을 적어 넣습니다. INDEX, LENGTH 함수를 같은 규칙으로 사용하며, CHANGE, NEWLIST, DELETE 대신 CHANGE_CLASS_LIST, NEW_CLASS_LIST, DELETE_CLASS를 사용합니다. #USE GAME; 이 명령어는 GAME 모듈을 불러오는 명령어입니다. -----GAME 모듈----- GAME_SCREEN; 게임 화면을 만듭니다. GAME_SIZE<100,200>; 게임 화면 크기를 가로 100, 세로 200으로 정합니다. GAME_CREATE_RECT<50,75,100,150,55,155,255,1>; 게임 화면 위에 사각형을 그립니다. 가로가 100, 세로가 150인 직사각형이 좌표 (50, 75) 위치에 생깁니다. 사각형의 좌표는 사각형의 정중앙으로 계산되며, 좌측 상단이 (0, 0)의 좌표 아래로 갈 수록 y값이 커지며 오늘족으로 갈 수록 x가 커집니다. 또한 색상은 rgb 순으로 55,155,255의 값을 가지며, 마지막 1은 0~1사이의 투명도로 1은 불투명, 0은 투명의 색을 가집니다. GAME_CREATE_CIRCLE<50,75,35,55,155,255,1>; 게임 화면 위에 원을 그립니다. 반지름이 35인 원을 좌표 (50, 75) 위치에 그립니다. rgb색상과 좌표 기준 등은 모두 GAME_CREATE_RECT 명령어와 동일합니다. GAME_DRAW_IMAGE<img,100,200,50,60>; 게임 화면 위에 img 이름의 이미지 변수를 가로 50, 세로 60의 크기로 좌표 (100, 200)에 그립니다. 이 명령어는 FILE 모듈을 불러와야 사용할 수 있습니다. GAME_DRAW_IMAGE<img,100,200,50,60,45>; 이전 명령어와 같게 동작하지만, 이미지를 45도 회전시켜 그립니다. GAME_WRITE<hello,100,200,35,55,155,255,1>; 이 명령어는 (100, 200) 좌표에 35px 크기와 rgba 55,155,255,1를 가지는 문자 hello를 입력합니다. GAME_CLEAN; 게임 화면 내부 요소를 모두 지웁니다. GAME_START{ SHOW "HELLO WORLD!"; } 게임을 시작하며, 정해진 fps값에 따른 시간마다 HELLO WORLD!를 출력합니다. GAME_MOUSE_X<> 이 명령어는 게임 스크린 위 마우스 X좌표를 가져옵니다. GAME_MOUSE_Y<> 이 명령어는 게임 스크린 위 마우스 Y좌표를 가져옵니다. GAME_FPS<a> 명령어는 1초당 GAME_START 내부 코드가 a번 작동하도록 fps를 설정하는 명령어입니다. -----INPUT 모듈----- INPUT_GETKEY a { SHOW "HELLO WORLD!"; } 는 이 명령어 실행 후 a키보드 버튼이 눌릴 시 HELLO WORLD!를 출력합니다. a자리에 들어오는 키보드 버튼은 소문자 알파벳 a~z입니다. INPUT_KEYUP b { SHOW "HELLO WORLD!"; } 는 이 명령어 실행 후 b키보드의 버튼을 누른 후 뗄 때 HELLO WORLD!를 출력합니다. a자리에 들어오는 키보드 버튼은 소문자 알파벳 a~z입니다. SET_FPS<a> 명령어는 INPUT_GETKEY와 INPUT_KEYUP등의 함수의 딜레이를 만듭니다. 1초에 a의 값만큼 실행되는 딜레이가 생깁니다. -----MATH 모듈----- MATH_RANDOM<1,100> 는 1부터 100까지의 정수 중 하나를 랜덤으로 반환합니다. MATH_ABS<a> a의 절댓값을 반환합니다. -----FILE 모듈----- SET_IMAGE img IS imageName; 이 코드는 img라는 이미지 변수 내부에 imageName이라는 이름을 가진 파일을 넣습니다. 프로젝트 폴더 내부 스크립트와 같은 공간에 있는 이미지만 저장할 수 있습니다. IMAGE_WIDTH<img> 는 img 이름의 이미지 변수에 해당하는 이미지의 가로 길이를 반환합니다. IMAGE_HEIGHT<img>도 같은 방법으로 동작합니다. SET_BACKGROUND_MUSIC backgroundMusic; 이 코드는 backgroundMusic이라는 이름의 mp3파일을 배경음악으로 설정합니다. 설정 후 자동 반복 재생됩니다. SET_AUDIO audio IS effectAudio; 이 코드는 audio라는 오디오 변수 내부에 effectAudio이라는 이름을 가진 파일을 넣습니다. PLAY_AUDIO audio; 오디오 변수 audio에 담긴 오디오 파일을 재생합니다.
